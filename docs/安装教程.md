# 安装教程

从零到面板出现，正常 2 分钟。出问题看最后一节。

---

## 1. 装 Tampermonkey

| 浏览器 | 地址 |
| --- | --- |
| Chrome | <https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo> |
| Edge | <https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd> |
| Firefox | <https://addons.mozilla.org/firefox/addon/tampermonkey/> |

装完在扩展栏能看到一个**黑色方块/两个圆点**的图标。

> 国产套壳浏览器（360、QQ、搜狗）大多能装 Chrome 版扩展，但 Tampermonkey 在这种浏览器里经常出怪问题。**建议直接用 Edge 或 Chrome。**

---

## 2. 安装脚本

### 方式 A：拖拽（最快）

1. 把 `duifene-autowatch.user.js` 下载到本地。
2. 打开 Tampermonkey 的**管理面板**（点图标 → 管理面板）。
3. 把文件从资源管理器**直接拖进浏览器窗口**。
4. 弹出安装页 → 点 **安装**。

### 方式 B：粘贴

1. 点 Tampermonkey 图标 → **添加新脚本**（Dashboard 里也可以点 `+`）。
2. 编辑区里默认有一堆模板代码，`Ctrl+A` 全选 → `Delete`。
3. 把 `duifene-autowatch.user.js` 的**全文**粘进去。
4. `Ctrl+S` 保存。

### 装成功的样子

Tampermonkey → 管理面板 → 已安装脚本里出现一行：

```
对分易 / SPOC 视频：自动观看 + 倍速伪装 + 进度上报录制回放   v1.2.0
```

前面有个绿色开关，**必须是开的**。

---

## 3. 打开课程页验证

1. 浏览器打开 <https://www.duifene.com/_FileManage/PC/StFileManage.aspx>
2. 登录，进到有视频的课程 / 资料页
3. 点开一个视频

正常情况下：

- 右下角出现深色面板 **DFE 自动观看**
- 视频**自己开始播**（如果被浏览器拦了自动播放，点一下播放键，脚本会接管）
- 声音是**静音**的
- 面板进度条在跑，而且跑得比正常快

按 `F12` → Console，会看到绿色 `[DFE]` 日志：

```
[DFE] 脚本已就绪；模式 fast 倍率 8 （对外 1x）
[DFE] 接管: 初始
[DFE] 视频源: https://xxx.duifene.com/....m3u8
```

## 4. 面板不见了 / 视频在 iframe 里

对分易有些页面把播放器放在**跨域 iframe** 里（比如 `player.xxx.com`），而脚本默认只匹配 `*.duifene.com`，所以在 iframe 里不会运行。

**解决**：打开脚本编辑页，在头部 `@match` 那一片加一行：

```javascript
// @match        *://*/*
```

然后 `Ctrl+S`。再确认 Tampermonkey 设置里 **配置模式 → 高级** 下的「注入 iframe」相关选项是允许的（默认就是允许）。

刷新课程页。此时脚本会对所有网站生效——但它在没有 `<video>` 的页面上只会挂个空转的定时器，不会弹面板（面板只在检测到视频后才出现）。

---

## 5. 装不上 / 不生效 的排查顺序

1. **看 Tampermonkey 图标上的数字**  
   有数字角标 = 页面里有脚本在跑。没角标 = 脚本没匹配上这个页面。

2. **确认脚本开关是绿的**，且「已启用」没被关掉。

3. **确认 URL 匹配**  
   `@match` 里有 `*://*.duifene.com/*`，`www.duifene.com` 能命中；如果是 `duifene.cn` 或学校的二级域名，需要自己加一行 `@match`。

4. **硬刷新** `Ctrl+Shift+R`，有些页面会缓存旧版本脚本。

5. **看 Console 有没有红色报错**  
   有 `[DFE] xxx 失败` 之类的日志就直接开 issue，把日志贴上来。

6. **换个浏览器试试**  
   某些浏览器的「增强保护 / 严格模式」会禁用用户脚本，或者对第三方脚本做 CSP 拦截。

---

## 6. 卸载

Tampermonkey → 管理面板 → 找到这个脚本 → 点垃圾桶。或者在课程页按 F5 前先把脚本开关关掉，页面会回到原始行为（包括限制快进）。
