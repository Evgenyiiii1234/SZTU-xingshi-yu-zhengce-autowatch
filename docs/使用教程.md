# 使用教程

一次完整的作业流程：**看完 → 拿到直链 → 转写 → 出笔记 → 交**。

---

## 0. 一次性准备

```powershell
cd duifene-watch
pip install yt-dlp av faster-whisper
```

只需要做一次。想跑测试再加 `npm i jsdom`。

- 第一次转写会自动下载模型（`small` 约 480 MB），之后走本地缓存。
- 不需要安装 ffmpeg：解码由 PyAV 自带的 FFmpeg 库完成，下载由 yt-dlp 内置的 HLS 下载器完成。

---

## 1. 让它自己看

1. 打开课程页，点开第一个视频。
2. 右下角面板出现后，确认三件事：
   - 视频在播（面板显示 `▶`）
   - 是静音的
   - 进度条跑得比正常快
3. 去干别的。**别把标签页切到后台太久**——Chrome 会节流后台标签页的定时器，虽然视频本身会继续播，但脚本的巡检会变慢。最稳的做法：把窗口放在旁边，或者开第二个窗口盖住它（不是最小化）。
4. 一节课播完，脚本会自动点「下一节」并接管新视频。如果平台按钮文案太特殊没点中，手动点一下，脚本 2 秒内接管。

### 中途弹题怎么办

对分易这类平台常见的“防挂机”手段：

| 弹窗 | 脚本行为 | 你要做的 |
| --- | --- | --- |
| “请确认你在观看” 按钮 | 响铃 4 声 + 标题前加 ⚠️ + 面板黄字 | 点一下确认，脚本继续 |
| 随堂测 / 弹题 | 同上 | 答题 |
| 人脸识别 | 同上 | 自己刷脸 |
| 验证码 | 同上 | 输入 |

脚本不会替你答题——它只保证**你不在电脑前时能被叫回来**。听到“嘀嘀嘀”就回来看看。

## 2. 拿到视频直链

在播放页点面板的 **`复制视频直链`**。

- 地址已经复制到剪贴板（同时打印在 Console 里）。
- 通常会有多条，优先选 `.m3u8` 结尾的那条；没有 m3u8 就选 `.mp4`。
- 如果是 `blob:https://...` 开头，说明播放器用 MSE 播放，脚本会从 `performance` 里捞出真实的分片地址，挑 `.m3u8` 的。
- **一条都没有** → 把视频播 10 秒，再点一次。有些播放器要等首片加载完才发请求。

---

## 3. 下载 + 转写 + 总结

### 一条命令

```powershell
.\go.ps1 "粘贴直链"
```

带参数：

```powershell
.\go.ps1 "直链" -Name 第3讲 -Model medium      # 指定文件名和更大模型
.\go.ps1 "直链" -Fast                          # 快速粗跑
.\go.ps1 "out\第3讲.mp4" -SkipDownload         # 视频已经下好了
```

### 分步（想控制每一步）

```powershell
# ① 下载
python pipeline/fetch_media.py "直链" -o out --referer "https://www.duifene.com/" --name 第3讲

# ② 转写
python pipeline/transcribe.py "out\第3讲.mp4" --model small --prompt "本课专业词1 专业词2"

# ③ 提纲 + 提示词包（+ 可选的大模型成稿）
python pipeline/summarize.py "out\第3讲.md"
```

### 产物说明

| 文件 | 用途 |
| --- | --- |
| `第3讲.mp4` | 原视频留档 |
| `第3讲.txt` | 带时间戳的文稿，`[12:34] …`，方便回查 |
| `第3讲.srt` | 字幕，拖进播放器可以边看边对 |
| `第3讲.md` | 每 75 秒合并一段的阅读稿，**给大模型喂料用这个** |
| `第3讲-outline.md` | 分节要点 + 高频概念表 + 待补充清单（没有 API key 时的底稿） |
| `第3讲-prompt.md` | 「指令 + 全文」打包，整份粘给网页版大模型立刻出稿 |
| `第3讲-summary.md` | 配了 API key 时自动生成的成稿 |

---

## 4. 出成稿

### 有 API key（自动）

```powershell
. .\env.example.ps1          # 里面填 SUM_BASE / SUM_KEY / SUM_MODEL
python pipeline/summarize.py "out\第3讲.md"
```

### 没有 API key（手动，效果一样）

1. 打开 `out\第3讲-prompt.md`
2. 全选复制，粘到 DeepSeek / 豆包 / Kimi / ChatGPT 任意一个
3. 把回复存成 `out\第3讲-summary.md`

`prompt` 里已经把要求写死了：本讲概要 → 分节要点 → 核心概念表 → 例题步骤 → 易错点 → 一句话回顾，并且要求“不要写‘视频中提到’这类废话”。

## 5. 交作业前检查

- [ ] 视频进度条满了 / 平台显示「已完成」
- [ ] 总结里的**时间点**和课程对得上（抽查两处）
- [ ] 专业术语被自动转写弄错的地方已经改回来（`small` 模型偶尔会错，`medium` 基本不错）
- [ ] 删掉 `outline` 里没填的「待补充」条目，别一起交了

## 6. 批量处理一整个课程

平台一节课一个直链，没有批量接口。可行的省事办法：

```powershell
# 一节课一条命令，攒在一个脚本里
$links = @(
  "https://.../lesson1.m3u8",
  "https://.../lesson2.m3u8"
)
$i = 1
foreach ($u in $links) {
  .\go.ps1 $u -Name ("第{0}讲" -f $i) -Model small
  $i++
}
```

转写是纯 CPU 的，一次跑一个就好，别并发（内存会炸）。
