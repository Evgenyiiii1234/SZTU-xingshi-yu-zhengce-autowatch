# 排错手册

先做这一步：**按 F12 打开 Console，看有没有绿色的 `[DFE]` 日志**。

- 有 `[DFE]` 日志 → 脚本在跑，问题在“接管/加速”这一层，看第二节。
- 没有 `[DFE]` 日志 → 脚本根本没注入，问题在“安装/匹配”这一层，看第一节。

---

## 一、脚本没跑起来

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| Console 里完全没有 `[DFE]` | URL 没匹配 `@match` | 脚本头部加 `// @match *://*/*`，`Ctrl+S`，硬刷新 |
| 面板出现了，但换了页面又没了 | 播放器在跨域 iframe | 同上；并确认 Tampermonkey 允许注入 iframe |
| Tampermonkey 图标没角标 | 脚本被停用 | 管理面板里把开关点绿 |
| 装了没反应，版本还是旧的 | 浏览器缓存了旧脚本 | `Ctrl+Shift+R`；或在管理面板里确认版本号是 `1.2.0` |
| 整个网站打不开 | 脚本语法错误导致页面崩溃 | 管理面板里看脚本是否报红；`node --check duifene-autowatch.user.js` 自检 |
| 提示“此脚本被 CSP 拦截” | 站点开了严格 CSP | 换 Edge/Chrome；Tampermonkey 的 `@grant none` 模式在部分站点会被 CSP 挡 |

## 二、脚本在跑，但视频不加速

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 面板显示 `▶ 1x (real 8x)`，但看起来是正常速度 | 播放器无视 `playbackRate`（自研解码/Canvas 渲染） | 点「接管播放」再试；仍然不行就是无解 → 改「保守模式 2×」，笔记走转写 |
| 视频一加速就自动退回 1× | 播放器每隔几秒纠一次速 | 脚本的巡检会拉回去，肉眼看是“抖动但总体在快”；日志里会反复出现 `接管` |
| 加速后声音消失 | 多数浏览器高倍速会静音音频 | 正常现象，不影响计时 |
| 进度条不动 | 播放器算进度用的是自己的计时器，不读 `video.currentTime` | 只能靠「回放打点」 |
| 一加速平台就弹“检测到倍速” | 服务端校验增速 | 降速到 2×，或用「回放打点」 |
| 播到一半自己暂停且拉不回来 | 播放器把 `pause` 逻辑写在了 `requestAnimationFrame` 里 | 面板点「接管播放」；或把页面保持在**可见**状态（别最小化） |

## 三、进度/成绩相关

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 视频看完了，平台显示未完成 | 平台统计的是“有效观看时长”，依赖它自己的心跳 | 用「回放打点」，或正常速度重看关键段 |
| 回放打点后进度还是 0 | 报文里的位置字段名不在识别表里 | 面板「上报记录」→ 复制 body → 看字段名 → 手动改 `POS_KEY` 正则 → 重装 |
| 回放打点报 401/403 | 缺 token / 签名过期 | 回放要在**同一个已登录页面**里做，且录完尽快回放；跨天基本都要重录 |
| 回放打点报 500 | body 被改坏了（比如把 `state` 当位置改了） | 一定先「演练」，看清 `[dry]` 那行再真发 |
| 打点成功但平台还是判异常 | 服务端还校验了别的字段（`endTime`、`stamp`） | 面板「导出记录」，把 json 发到 issue，我加字段规则 |

## 四、下载相关

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| `403 Forbidden` | 缺登录态或 Referer | `--referer "https://www.duifene.com/"`；仍失败见下一条 |
| 拿到的是错误页（几百字节） | 链接带时效签名，已过期 | 回播放页重新「复制视频直链」 |
| 下载只有几 MB / 时长很短 | 抓到了试看片段或广告片 | 把视频拖到后半段再抓一次直链 |
| `Unsupported URL` | 抓到的是 `blob:` 而不是真实地址 | 播 10 秒再点「复制视频直链」，从多条里挑 `.m3u8` |
| 加密 HLS（`#EXT-X-KEY`）下不下来 | yt-dlp 内置下载器不解密 | 换 720p 以下的清晰度重抓；或用浏览器插件把整段 m3u8 存下来手动喂 |
| 卡在 `[download] 0.0%` | 分片服务器限速/需要特定 Header | 加 `--cookies cookies.txt`；或 `--max-height 480` 降清晰度 |

**复制 Cookie 的正确姿势**：

1. F12 → Network → 找到那个 `.m3u8` 或 `.mp4` 请求
2. 右键 → `Copy` → `Copy as cURL`
3. 把其中的 `-H 'Cookie: xxx'` 里的值，按 Netscape 格式存成 `cookies.txt`：

```
.duifene.com	TRUE	/	FALSE	0	SESSION	你复制的值
```

4. `python pipeline/fetch_media.py "URL" --cookies cookies.txt`

## 五、转写相关

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| `TypeError: open() got an unexpected keyword argument 'metadata_errors'` | PyAV 版本太新 | 已在 `patch_av_compat()` 里修掉；如果还报，说明你改过 import 顺序，确保补丁在 `import faster_whisper` 之前执行 |
| 模型下载卡住 / 超时 | HuggingFace 直连不稳 | 脚本会自动切 `hf-mirror.com` 重试；仍失败就 `$env:HF_ENDPOINT="https://hf-mirror.com"` 再跑，或手动下模型目录用 `--model "本地路径"` |
| 没有识别到语音 | 纯音乐 / 无人声 / 音轨是 5.1 且解码异常 | 先 `--model tiny` 试；确认原视频有人说话 |
| 满屏重复句 | `condition_on_previous_text` 在长静音后崩了 | 加 `--fast`（会关掉它），或换 `--model medium` |
| 繁简混杂、错别字多 | 模型太小 | 换 `small`/`medium`；加 `--prompt` 写本课术语 |
| 内存爆 / 卡死 | 模型太大 + 视频太长 | `--model base`；一次只跑一个 |
| 时间戳错位 | 视频开头有长静音，VAD 切掉了 | 正常，VAD 会让时间戳对齐“有声音的片段”，核对时看相对顺序 |

## 六、其他

**Q：切到后台标签页会不会被发现？**  
Chrome 会节流后台标签页的定时器（最慢 1 次/分钟），但 `<video>` 本身继续播。脚本的巡检变慢意味着“被暂停后拉回来”会延迟。**别最小化窗口**，用另一个窗口盖住最稳。

**Q：多个视频同时开会不会串？**  
每个标签页各跑一份脚本、各存一份 `localStorage`，不会串。但转写是 CPU 密集的，别同时跑多个。

**Q：怎么彻底恢复原样？**  
Tampermonkey 里把脚本开关关掉，再 F5。所有补丁都只存在于当次页面生命周期内，刷新即失效。

**Q：还搞不定？**  
开 issue 时请带上：浏览器版本、脚本版本、F12 Console 里所有 `[DFE]` 日志、以及（如果是打点问题）`导出记录` 的 json。这些信息齐了基本一次就能定位。
